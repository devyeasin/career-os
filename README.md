# Career OS

**All-in-one Life · Deen · Study · Work dashboard**

Built for serious self-improvement — especially for students and aspiring developers who want everything in one clean, professional place.

## Features

- **Live clock** + date
- **Interactive calendar** (any year, day notes)
- **Focus / Pomodoro timer** (25 / 45 / 60 min + breaks)
- **Stopwatch** with laps
- **Alarm** (browser notifications)
- **Calculator**
- **Live currency converter** (USD ↔ BDT and more)
- **Multi-page Notes**
- **YouTube Lofi / study music player** (paste any link)
- **Live weather** (Dhaka by default)
- **Daily inspirational quote** + **Daily Quran verse**
- **Deen module**: Prayers tracker + streak, Tasbih, Quran pages/minutes, Surah learning list
- **Work**: To-do list + Ideas inbox
- **Study**: Topics + Skill roadmap
- **Habits** 30-day visual grid
- **4-Month Plan** with milestones & progress
- **Daily Log** (deen, work, study, money, health)
- **Command Palette** (`Ctrl + K` / `⌘ + K`)
- **Light / Dark mode**
- **PWA** — installable as desktop/mobile app + basic offline support
- All data saved in **localStorage** (works offline)

## How to use

1. Download or clone this repo
2. Open `index.html` in any modern browser  
   **or** run a simple local server:
   ```bash
   npx serve .
   ```
3. (Optional) Install as app: Chrome/Edge → ⋮ → Install Career OS

## For GitHub

Just push the whole folder. No build step required.

```bash
git init
git add .
git commit -m "Career OS — first version"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/career-os.git
git push -u origin main
```
